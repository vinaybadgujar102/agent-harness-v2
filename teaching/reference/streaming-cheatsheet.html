Step / delta Show user? Harness event

interaction.completed.status

Status Meaning Agent
requires_action Tool call emitted; waiting on you Execute tool → append function_result → next stream
completed Model turn finished If text accumulated → return to user; stop loop
failed / cancelled Error / abort error event; surface to user
