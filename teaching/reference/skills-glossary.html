Agent Skills glossary

One term, one meaning. Lessons must use these words.

Skill
A directory with a required SKILL.md. Metadata plus instructions (and optional scripts/references). Not a model tool schema.
Tool
A harness-registered function the model can call (read_file, write_file, list_dir). Skills use tools; they are not tools.
SKILL.md
YAML frontmatter + Markdown body. Required fields: name, description.
Progressive disclosure
Load cheap metadata for every skill; load the body only after selection; load bundled files only when the body points at them.
Discovery index
Compact list injected at session start so the model can choose. Always: name + description. In this harness also the workspace path to SKILL.md, because activation is read_file.
Activation
Model matches a description, then loads that SKILL.md body into context. In this repo: one read_file on the index path. Not a new tool schema.
name (frontmatter)
Skill id. Must equal the parent directory. Spec charset: lowercase alphanumeric and hyphens only.
description (frontmatter)
What the skill does and when to use it. This is the discovery index text, not the procedure.
