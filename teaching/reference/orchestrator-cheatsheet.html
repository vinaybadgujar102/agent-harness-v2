Agents-as-tools (pick this for tuffy)

Lead keeps the conversation. Workers run inside a tool call. User never talks to workers directly. OpenAI: orchestration, LangChain: subagents.

Worker brief (minimum)

  1. Goal — one sentence outcome
  2. Inputs — paths, constraints, what not to touch
  3. Tools — subset (often read-only explore)
  4. Done — verifiable finish line
  5. Return — structured summary for merge, not raw log

Guardrails

  • Workers: no delegation tool (break recursion)
  • Hard max depth (e.g. lead → worker only)
  • Parallel workers only when tasks are independent
  • Cap iterations / tokens per worker
