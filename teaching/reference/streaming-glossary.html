Streaming glossary

Terms for this repo. Cheat sheet, harness today, lesson 0001.

InteractionStep (today)

One completed model turn: either tool_call_needed (name, args, call_id) or message (full text). Produced only after the provider request finishes.

HarnessEvent

Typed union in types.ts. Full mapping: harness-events.html.

Provider stream

SDK or HTTP SSE from Google, OpenAI, or Anthropic. You parse vendor chunks; you do not expose raw chunks to UI unless debugging.

Step (Google Interactions)

One leg of an interaction: model_output, function_call, thought, etc. Streaming delivers each step as step.start → step.delta* → step.stop.

arguments_delta

Partial JSON string for tool args on Google streams. Accumulate until step.stop, then JSON.parse before tool.execute.

Transport (product layer)

How events reach the user: CLI stdout, HTTP SSE (Bun.serve), or WebSocket. Orthogonal to provider parsing.

Batch gate (tool execution)

Rule: never run registry tools until the tool call is complete and valid. Streaming can show “calling bash…” early; execution waits at the gate.
