1. Read this first (primary source)

Anthropic: multi-agent research system — lead agent plans and delegates; workers run in parallel with isolated tasks; lead synthesizes. Same family as LangChain subagents (supervisor + tools).

2. Vocabulary

Lead (orchestrator)
The agent the user talks to. Plans, calls tools, may spawn workers, merges their summaries into one answer.
Sub-agent (worker)
Short-lived nested run: own system prompt, often fewer tools, returns a bounded result to the lead via a tool result — not direct chat.
Agents-as-tools
Lead stays owner of the reply; workers are invoked like read_file, not a handoff that replaces the lead.

3. Your harness today

User → LovableAiAgent.createStream / create
         → GoogleAgentProvider (one conversation)
         → tool loop: read_file | write_file | list_dir

The loop in apps/backend/src/abstraction/agent.ts already orchestrates tools. It does not yet orchestrate other agents. The system prompt already nudges parallel subagents when a delegation tool exists — but createAgent never registers one.

Skills (lesson 0009) are procedure files the lead loads with read_file. They are not sub-agents. A worker might follow a skill; the skill does not replace the worker runtime.

4. Target shape (design, not shipped)

Lead loop
  ├─ read_file / write_file / list_dir  (unchanged)
  └─ run_subagent({ role, brief, toolProfile })
        └─ new LovableAiAgent (worker prompt, restricted tools)
        └─ tool result → { summary, status }  (not full worker transcript)

Parent conversation keeps user context small — same idea as Inngest sub-agent delegation: parent sees summary only.
