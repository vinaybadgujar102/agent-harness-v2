Activation is read_file

One win: you can name the first tool call after a description matches, then the second call the body demands.

Lesson 0008 · Cheatsheet · Glossary

1. Read this first (primary source)

Anthropic: How Skills work — after a request matches a description, Claude reads SKILL.md from disk (they use bash cat). Only then does the body enter context. Same story in agentskills.io (activation) and paper Appendix A.2.

This harness has no bash skill loader and no extra function named activate_skill. The equivalent call is read_file on the path from the index.

2. Order (do not skip)

  1. Index already in the system prompt (Level 1). Bodies are not.
  2. User request. Model matches a description.
  3. First tool: read_file that SKILL.md.
  4. Harness returns file text as a tool result. Now the body is in the conversation.
  5. Next tools follow the body: for your implement-plan skill, that is read_file on .tuffy/plans/active.md before edits.

Writing code before step 3 means the model is improvising, not using the skill. Writing code after step 3 but before reading the plan means it ignored your procedure.

3. Index for this drill

When a listed skill matches, read_file its path.
- implement-plan (.tuffy/skills/implement-plan/SKILL.md): Use this skill when implementing tasks from the active project plan and tracking their progress.
- explore-workspace (.tuffy/skills/explore-workspace/SKILL.md): List and read files to understand a repo. Use when the user asks to explore or summarize the workspace.

4. Drill — pick the next call

Wrong buttons stay marked. Keep going until the green one.
