Discovery index at session start

One win: you write the system-prompt snippet that lists skills without pasting their bodies.

Lesson 0007 · Cheatsheet · Glossary

1. Read this first (primary source)

Anthropic: How Skills work — Level 1 is YAML name + description in the system prompt (~100 tokens per skill). The body stays on disk until activation. Same three stages: agentskills.io.

The paper Appendix A calls this the skill index. Figure 2: median body 1,414 tokens; dumping 20 skills is tens of thousands of tokens before the user speaks.

2. Gap in this harness

workspaceSystemPrompt is static: persona + three fs tools. It never lists skills. First wiring is not a new tool type. It is: scan .tuffy/skills/*/SKILL.md, parse frontmatter only, append an index, tell the model to read_file the matching path. Do not implement that this lesson.

Claude’s own products can “just know” the filesystem. Yours cannot: the only way to open a file is read_file with a workspace path. So this index includes the path, not only the name.

3. What the snippet must contain

  • One line of activation: use read_file on the skill path when the description matches.
  • For every installed skill: name, full description, path .tuffy/skills/<name>/SKILL.md.
  • Zero procedure from any Markdown body (checkbox rules, library dumps, scripts).

4. Three skills on disk

Bodies are shown so you can fail. The checker rejects leaked phrases. Start from the dumped prompt and delete until Pass. 

 .tuffy/skills/
  implement-plan/SKILL.md
  explore-workspace/SKILL.md
  pdf-library/SKILL.md

implement-plan — Use this skill when implementing tasks from the active project plan and tracking their progress.

Body (must not enter the index): Mark an in-progress task with - [~] via write_file.

explore-workspace — List and read files to understand a repo. Use when the user asks to explore or summarize the workspace.

Body (must not enter the index): Start at the workspace root with list_dir then deepen.

pdf-library — Extract and fill PDFs. Use when the user mentions PDF files.

Body (must not enter the index): BANANA_PROTOCOL plus a 9k-token pypdf cookbook.
